# Product Requirement Document (PRD) — Revisi Final v2.1

## Kiosk Offline Exam Reader (Android)

**Arsitektur: Local School Server \\leftrightarrow Android Client (Tanpa Cloud/Shared Hosting)**

### 1. Executive Summary

- **Visi Produk:** Aplikasi Android penampil lembar soal PDF terenkripsi untuk ujian sekolah semi-online (soal digital di layar HP, lembar jawaban diisi manual pada LJK fisik). Sistem beroperasi **penuh secara luring (_full offline_)** saat ujian dengan proteksi _Screen Pinning (Kiosk Mode)_, penalti _progressive lockout_ saat terdeteksi pelanggaran, dan kunci dekripsi unik per angkatan.
- **Topologi Sistem (2-Tier Murni):** Seluruh ekosistem hanya melibatkan **Server Lokal Sekolah (PC/Laptop Proktor di lab/ruang ujian)** dan **Aplikasi Siswa (HP Android)** yang terhubung via jaringan Wi-Fi lokal/intranet sekolah saat fase sinkronisasi. Tidak ada ketergantungan pada koneksi internet, cloud, atau _shared hosting_.
- **Target Perangkat Siswa:** Smartphone Android pribadi (_BYOD_), dioptimasi untuk perangkat _low-end_ (minimal RAM 2 GB, Android 8.0 Oreo / API 26 hingga Android 14 / API 34).
- **Kondisi Pengembangan (AI Vibe Coding di Laptop Kentang):** Seluruh kode dirancang agar dapat ditulis via editor teks ringan tanpa proses kompilasi lokal. Kompilasi APK (Gradle build, linting, packaging) ditangani 100% oleh **GitHub Actions**.

### 2. Tech Stack & Dependensi Minimal

Semua pustaka dipilih untuk menjaga konsumsi RAM di bawah **45 MB** dan ukuran APK di bawah **5 MB**:

- **Bahasa & Kompiler:** Kotlin 1.9.22, JDK 17, Gradle 8.6, AGP 8.3.0.
- **UI Toolkit:** Android Native XML View + ViewBinding (beban RAM dan build time jauh lebih hemat daripada Jetpack Compose).
- **Jaringan Lokal (Sinkronisasi H-7):**
  - com.squareup.okhttp3:okhttp:4.12.0 (Mengunduh manifest dan file .enc langsung dari IP LAN server sekolah).
  - org.jetbrains.kotlinx:kotlinx-serialization-json:1.6.3 (Parser JSON cepat tanpa refleksi).
- **Kriptografi & Penyimpanan:**
  - androidx.security:security-crypto:1.1.0-alpha06 (EncryptedSharedPreferences untuk menyimpan sisa waktu, state penalti, dan status mapel).
  - javax.crypto.Cipher (AES/GCM/NoPadding) & PBKDF2WithHmacSHA256.
- **Engine Penampil PDF:**
  - android.graphics.pdf.PdfRenderer (Bawaan native Android OS, overhead 0 MB di APK).
  - Bitmap.Config.RGB_565 (Menghemat konsumsi RAM hingga 50% dibanding ARGB_8888).

#### B. Skema Penyimpanan Lokal (EncryptedSharedPreferences)

- server_ip: Menyimpan alamat IP server lokal terakhir yang digunakan (default: 192.168.1.100:8080).
- master_pin_hash: Hash SHA-256 dari PIN pengawas untuk verifikasi offline.
- active_exam_id: ID ujian yang sedang dibuka.
- remaining_exam_seconds: Sisa waktu ujian utama (diperbarui setiap 5 detik).
- violation_count: Jumlah akumulasi pelanggaran sesi aktif.
- remaining_ban_seconds: Sisa waktu penalti yang sedang berjalan.
- last_boot_count: Nilai Settings.Global.BOOT_COUNT untuk mendeteksi _reboot_ curang.
- finished_exams: Set ID ujian yang sudah ditandai SELESAI (tidak dapat diakses lagi).

```
[Koneksi Wi-Fi Lab Sekolah (H-7)]
               │

   [Input IP Server & Sinkron] ──► Unduh Manifest & Seluruh Berkas .enc

               │
               ▼
    [Pilih Mata Pelajaran] ──(Cek Syarat: Mode Pesawat ON, BT OFF)──► Gagal? Tombol Kunci
               │ (Memenuhi Syarat)
               ▼
      [Input Token Mapel] ──(Derivasi AES-GCM via PBKDF2)──► Token Salah? Error
               │ (Token Cocok)
               ▼
     [Aktivasi Kiosk Mode] ──► startLockTask() + Unlink Temp PDF + Tampilkan Soal
               │
       ┌───────┴────────────────────────┐
       ▼                                ▼
(Pengerjaan Normal)           (Terdeteksi Pelanggaran)
       │                                │
       │                                ▼
       │                    [Layar Merah / Penalti Ban]
       │                    (Timer Ujian Tetap Berjalan)
       │                                │
       │                                ▼
       │                    (Masa Ban Selesai & Syarat OK)
       │                                │
       └────────────────┬───────────────┘
                        │
                        ▼
    (Timer Habis 00:00 atau Dibuka PIN Pengawas)
                        │
                        ▼
      [Tutup PDF, Status FINISHED, Unpin Layar]
```

#### A. Layar Dashboard & Sinkronisasi

- **Input Konfigurasi Server:** Kolom input IP dan Port server lokal sekolah dengan tombol simpan cepat.
- **Tombol Sinkronisasi:** Membaca endpoint /manifest.json, mengunduh berkas .enc yang belum ada di penyimpanan lokal, dan memverifikasi integritas via SHA-256 checksum.
- **Filter Angkatan:** Tab navigasi untuk menyaring daftar ujian (Kelas 10, Kelas 11, Kelas 12).
- **Indikator Kesiapan Hardware:**
  - Status Mode Pesawat (Hijau jika ON, Merah jika OFF).
  - Status Bluetooth (Hijau jika OFF, Merah jika ON).

#### B. Masuk Ujian & Dekripsi Ramah Memori

1. Siswa memilih kartu ujian \\rightarrow Muncul dialog input token angkatan.
2. Derivasi Kunci: Aplikasi membentuk kunci AES-256 dari kombinasi Token Angkatan + pbkdf2_salt_hex menggunakan 10.000 iterasi PBKDF2.
3. Stream Decryption: Aliran byte dari berkas .enc didekripsi secara streaming (buffer 8 KB) dan ditulis ke File(context.cacheDir, "temp_active.pdf").
4. Jika token salah, enkripsi GCM otomatis melempar AEADBadTagException, file sementara langsung dibersihkan, dan sistem menampilkan pesan penolakan.
5. Jika token benar, aplikasi mengeksekusi teknik **Unlinked Temporary File**:
   - Membuka ParcelFileDescriptor dengan mode MODE_READ_ONLY.
   - Memanggil tempFile.delete() seketika. File fisik terhapus dari sistem penyimpanan sekunder, namun data tetap bisa dibaca oleh PdfRenderer di memori hingga proses selesai.

#### C. Kiosk Exam Viewer & Custom Status Bar

- **Bilah Status Atas (Tinggi 48dp, Latar Gelap #0F172A, Permanen):**
  - **Kiri:** Label Mapel dan Tingkat Angkatan.
  - **Tengah:** Countdown Timer Ujian (HH:MM:SS) berbasis SystemClock.elapsedRealtime(). Warna otomatis berubah menjadi kuning saat \\le 15 menit, dan berkedip merah saat \\le 5 menit.
  - **Kanan:** Indikator Halaman aktif, Persentase Baterai Real-time (ACTION_BATTERY_CHANGED), dan Tombol Gembok Akses Pengawas.
- **Kanvas PDF:**
  - Memanfaatkan RecyclerView vertikal dengan PdfRenderer.
  - Halaman dirender dalam format **Bitmap.Config.RGB_565**.
  - Bitmap pada halaman yang tidak terlihat di layar langsung di-_recycle_ (onViewRecycled), menjaga total alokasi heap memori tetap di kisaran **20–35 MB**.
  - Mendukung gestur cubit untuk memperbesar teks (_pinch-to-zoom_) dari skala 1.0x hingga 3.0x.

#### D. Sistem Penguncian & Deteksi Anti-Curang

- **Screen Pinning Enforcement:** Aplikasi memanggil startLockTask(). Selama status getLockTaskModeState() belum berstatus PINNED (misal pop-up konfirmasi sistem masih aktif atau siswa membatalkannya), kanvas soal ditutup oleh layar hitam peringatan.
- **Grace Period Sensor:** Memberikan jeda waktu 3 detik setelah status PINNED aktif sebelum mengaktifkan sensor penalti untuk mencegah salah deteksi.
- **Pemicu Pelanggaran Aktif:**
  1. Kehilangan fokus jendela (onWindowFocusChanged(false)) akibat mencoba membuka _floating apps_ atau _split screen_.
  2. Mode Pesawat dinonaktifkan (AIRPLANE_MODE_ON == 0).
  3. Bluetooth diaktifkan.
  4. Kabel USB terhubung dalam mode transfer data.
  5. Nilai BOOT_COUNT bertambah (terdeteksi me-restart perangkat secara sengaja).

#### E. Skema Penalti Berjenjang (Progressive Lockout)

Ketika pelanggaran terpicu:

- Berkas PDF langsung ditutup dari layar (_unrender_).
- Layar menampilkan **Overlay Merah Penuh** berisi jenis pelanggaran dan hitung mundur masa ban.
- **Waktu ujian utama TIDAK DIPENYETELAN ULANG dan TETAP BERJALAN di latar belakang.**

| Pelanggaran Ke- | Durasi Ban              | Respons Sistem                                                  |
| --------------- | ----------------------- | --------------------------------------------------------------- |
| **1**           | **60 Detik (1 Menit)**  | Getar 500ms, layar peringatan merah, hitung mundur 60 detik.    |
| ---             | ---                     | ---                                                             |
| **2**           | **180 Detik (3 Menit)** | Getar berkala, layar merah, hitung mundur 180 detik.            |
| ---             | ---                     | ---                                                             |
| **3**           | **300 Detik (5 Menit)** | Peringatan keras, hitung mundur 300 detik.                      |
| ---             | ---                     | ---                                                             |
| **4+**          | **Terkunci Total**      | Layar hitam: _"Ujian Diblokir Permanen. Laporkan ke Pengawas."_ |
| ---             | ---                     | ---                                                             |

_Masa ban hanya dapat selesai jika hitung mundur mencapai 00:00 DAN seluruh syarat (Mode Pesawat ON, Bluetooth OFF, Layar PINNED) telah dipatuhi kembali oleh siswa._

#### F. Akses Otoritas Pengawas (Master PIN)

- Pengawas dapat menekan ikon gembok pada Custom Status Bar.
- Memasukkan **6 Digit Master PIN**. Validasi dilakukan secara offline dengan mencocokkan SHA-256 PIN terhadap master_pin_sha256 yang tersimpan saat sinkronisasi.
- Opsi Pengawas:
  1. **Reset Pelanggaran & Buka Ban:** Digunakan jika penalti terpicu akibat pop-up sistem tak terduga (misal peringatan baterai lemah 15%).
  2. **Akhiri Ujian Lebih Awal:** Menutup sesi pengerjaan siswa yang sudah selesai mengisi LJK fisik sebelum waktu ujian habis.

### 6. Pipeline CI/CD GitHub Actions (Zero-Local Build)

Konfigurasi ini memastikan aplikasi dapat dikompilasi secara otomatis di cloud tanpa membutuhkan gradlew wrapper biner di laptop lokal.

Simpan pada .github/workflows/build-apk.yml:

```
name: Build Android APK (Local Server Edition)

on:
  push:
    branches: [ "main" ]
  workflow_dispatch:

jobs:
  build:
    name: Build & Package APK
    runs-on: ubuntu-latest

    steps:
      - name: 1. Checkout Source Code
        uses: actions/checkout@v4

      - name: 2. Set up JDK 17
        uses: actions/setup-java@v4
        with:
          distribution: 'temurin'
          java-version: '17'

      - name: 3. Setup Gradle 8.6
        uses: gradle/actions/setup-gradle@v4
        with:
          gradle-version: '8.6'
          cache-read-only: false

      - name: 4. Compile Debug APK
        run: gradle assembleDebug --stacktrace --no-daemon

      - name: 5. Upload APK Artifact
        uses: actions/upload-artifact@v4
        with:
          name: Kiosk-Exam-Reader-Debug
          path: app/build/outputs/apk/debug/app-debug.apk
          retention-days: 14
```

### 7. Aturan Implementasi Vibe Coding (AI Prompts Guardrails)

Ketika meminta AI untuk memproduksi file kode spesifik, terapkan batasan berikut:

1. **Cleartext Traffic Policy:** Tambahkan android:networkSecurityConfig="@xml/network_security_config" pada AndroidManifest.xml untuk mengizinkan HTTP lokal ke subnet privat tanpa memicu pemblokiran keamanan Android 9+.
2. **Tanpa Aset Gambar Biner:** Gunakan hanya file XML Drawable vektor untuk seluruh ikon (baterai, status, gembok, panah navigasi).
3. **Pendaftaran Receiver Aman (API 34):** Gunakan ContextCompat.registerReceiver(..., ContextCompat.RECEIVER_NOT_EXPORTED) pada semua pendaftaran BroadcastReceiver runtime.
4. **Lifecycle-Aware Timer:** Gunakan coroutine viewModelScope dengan delay 1 detik berbasis perhitungan SystemClock.elapsedRealtime() untuk mencegah kebocoran memori (_memory leaks_).

### 8. Rencana Eksekusi Bertahap

- **Milestone 1:** Konfigurasi Gradle dasar, AndroidManifest dengan izin jaringan lokal & kiosk mode, struktur Activity utama, dan verifikasi pipeline GitHub Actions sukses menghasilkan APK pertama.
- **Milestone 2:** Modul koneksi lokal LocalSyncManager (unduh manifest & file .enc via IP lokal) + UI Dashboard pemilihan angkatan.
- **Milestone 3:** Mesin kriptografi CryptoEngine (PBKDF2 + AES-GCM streaming) + PdfRenderer teroptimasi RGB_565 dengan dukungan gestur zoom.
- **Milestone 4:** Custom Status Bar, integrasi startLockTask(), sensor EnvironmentMonitor, dan logika penalti ban bertingkat PenaltyManager.
